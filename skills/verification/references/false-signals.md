# 假信号清单（False signals）

按"看着像成功、其实是假象"分类。每条给：**怎么识别 → 通用验证手法 → 实例**。

## A. 执行类

| 假信号 | 识别 | 验证手法 | 实例 |
|---|---|---|---|
| 退出码 0 但没跑 / 出错 | 崩溃被框架吞掉、错误只打日志 | runner 里额外 grep 错误模式；或在被测代码里输出一个"我跑到了"的标记 | 某引擎的 `SCRIPT ERROR` 不改变退出码；更狠的一次：传入不存在的脚本，它打了 3 行 `ERROR:` 却**退出 0**，我的 runner 差点判"通过"——把 `^ERROR:` 加进默认模式才抓到 |
| 挂着不退出 | 进程还在、日志停在某处 | 执行器必须有超时 + 报告"TIMEOUT"；不要靠 sleep 等 | 无主场景时 `--quit-after` 报错后永久阻塞 |
| 提前退出 | 期望跑到第 N 步，实际第 2 步就结束 | 断言"结束标记"存在，而不只断言"没报错" | 超时 kill 掉进程后，日志只写了半截 |

## B. 度量类

| 假信号 | 识别 | 验证手法 | 实例 |
|---|---|---|---|
| 指标 > 0 就以为对 | 数字动了，但内容可能是错的 | 配一个语义断言（内容/位置/可见性） | 图元数 600 说明提交了绘制，但三角形绕序反了 → 画面纯黑 |
| 计数器被封顶 | 数字总等于某个常数 | 用独立计数器；比较"期望数量 vs 记录数量" | 环形缓冲的 `size()` 当收包数，误判只收到 8 个包 |
| 采样窗口错配 | 样本很短、采样间隔很长 | 打印每个采样点的时间戳 | 0.16 s 的音效配 20 帧（≈330 ms）采样窗口，差点误判"没声音" |
| 基准被优化掉 | 时间接近 0 | 让结果逃逸（volatile/参与返回），并对照朴素实现 | C++ 循环测出 0.0 ms，加 volatile 后 2.2 ms |
| 环境差异 | 同一代码两台机器数字差 10 倍 | 记录机器/版本/是否开窗口/是否并行 | headless 用 dummy 渲染，渲染指标全是 0 |

## C. 副作用类

| 假信号 | 识别 | 验证手法 | 实例 |
|---|---|---|---|
| 工具返回 success 但没生效 | 查外部状态 | 查进程 / 端口 / 文件 / 窗口列表，别信返回值 | 编辑器启动工具回 `success`，实际没有编辑器进程 |
| 文本替换没匹配上 | 改动"成功"了但行为不变 | 替换后立刻 grep 回读；锚点选稳定内容 | 锚点所在段落已被工具剪枝，replace 静默什么都没做，功能一直不生效 |
| 编辑器/格式化器重写了文件 | 你的注释/顺序被改 | 动手前 commit，事后 diff；只信语义不信托管格式 | 编辑器保存时给每个节点加 ID、把 `x = {&"": v}` 改写为 `x/ = v` |
| 端口/文件名被占用 | "创建失败"类错误 | 多进程测试前先清理残留；用随机端口 | 残留服务进程占端口，新实例直接报绑不上 |

## D. 语义类（最难，靠实测）

| 假信号 | 识别 | 验证手法 | 实例 |
|---|---|---|---|
| 名字相同、语义不同 | 文档描述模糊 | 写最小对照实验，一次只改一个变量 | "扫掠检测"的 API 碰到第一个物体就停，不带多点结果；拿它做多点检测永远只得到 1 条 |
| 相邻 ≠ 连通 | 几何/图结构上"看着连上了" | 直接查连通性/可达性，不看几何 | 两块网格只有部分边重合 → 不连通；必须**完全一致的边** |
| 缺失依赖时不报错 | 功能静默降级 | 断言"依赖存在"，缺失时显式失败或跳过并说明 | 2D 定位音缺少监听相机 → 完全不发声，且无任何警告 |
| 顺序假设错误 | 生命周期/回调顺序靠猜 | 逐帧打印状态变化 | 帧信号在节点回调**之前**发出，`await` 一帧读到的是处理前的值 |
| 坐标系/符号算错 | 结果"镜像"或反向 | 断言具体数值而非"变了"，并把数学写进注释 | 绕 +X 轴 90°：+Y → +Z（不是 -Z） |
| 测量被副作用污染 | 对照组本身带状态 | 对照要"从头干净"，不要中途移除/还原 | 移除相机后视口仍残留监听者引用 → 误得"无相机也能发声" |

## 通用做法总结

1. 每个关键结论写下来时，旁边写清**用的是哪两个观察面**。
2. 任何"新增功能/修复"前，先写能失败的断言（红→绿）。
3. 任何数字，先问"它可能怎么骗我"；任何外部调用，先问"它没生效我怎么会知道"。
4. 同一假设失败两次 → 插桩，不再推理。
